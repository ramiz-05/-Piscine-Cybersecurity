# Project 03: JavaScript & Interactivity ⚡

This repository contains my solutions for **Project 03: JavaScript & Interactivity**. While HTML provides the structure and CSS handles the presentation, this project focuses on using JavaScript to breathe life into the browser and create dynamic, interactive web experiences.

## 📁 Repository Structure

| Directory | Exercise Name | Description | Concepts Covered |
| :--- | :--- | :--- | :--- |
| `ex00/` | Variables & Types | Introduction to core JavaScript fundamentals. | Variable declarations (`let`, `const`), primitive data types, basic operators. |
| `ex01/` | Functions & Conditions | Implementing logic and reusable code blocks. | `if/else` statements, logical operators, function declarations, parameters, return values. |
| `ex02/` | The Live DOM Tree | Dynamically manipulating the webpage content. | Document Object Model (DOM) traversal, selecting elements, modifying text and attributes. |
| `ex03/` | Event-Driven Web | Handling user interactions and browser events. | Event listeners (`click`, `input`, etc.), event objects, dynamic CSS class toggling. |
| `ex04/` | Interactive App | Building a comprehensive, interactive application. | Combining DOM manipulation, state management, and event handling into a functional web app. |
