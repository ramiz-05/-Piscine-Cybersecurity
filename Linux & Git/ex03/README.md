# Discovery Web

## Project Overview
This repository is part of the Discovery Web exercises.  
It demonstrates basic Git usage, project documentation, and secure authentication with SSH.

## Why Git Makes Development Easier
Git simplifies development in several ways:

- **Code Safety**: Every version of your code is stored, so you can always roll back to a stable state if something breaks.
- **History Tracking**: Each change is recorded with a timestamp, author, and commit message, making it easy to understand the evolution of the project.
- **Collaboration**: Teams can work together seamlessly, review each other's changes, and merge contributions without overwriting each other's work.
- **Experimentation**: Branches allow developers to test new features or ideas without affecting the main codebase.

## How to Use
1. Clone the repository.
2. Follow the workflow steps in `git_workflow.txt`.
3. Push your changes to GitHub (via HTTPS or SSH).
