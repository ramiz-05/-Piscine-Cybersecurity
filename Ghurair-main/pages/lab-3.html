Security Lab 03

Prototype Pollution

Send one crafted JSON object and make every user look like an admin.

OWASP A08:2025 · Software or Data Integrity Failures CWE-1321

01. What It Is

Prototype pollution happens when attacker input changes the shared prototype that every JavaScript object inherits from. One polluted property, such as isAdmin, then appears on objects that never set it, which can break permission checks. It is OWASP A08:2025 Software or Data Integrity Failures and CWE-1321 (a child of CWE-915).

03. Why It Matters

A polluted prototype can change permission checks, settings and feature flags across the whole app, and in some Node.js apps it has led to remote code execution.

Real incident: In 2019, defaultsDeep in lodash, one of the most used npm libraries, was found to be open to prototype pollution (CVE-2019-10744, rated 9.1 Critical). It was fixed in lodash 4.17.12.

04. The Fix

Skip the dangerous keys __proto__, constructor and prototype, and only reuse properties the target owns.

Dangerous-key filtering Fixed

Security improvement: The highlighted line drops the __proto__ key before it is merged, so the same payload no longer reaches the shared prototype. Safer alternatives are Object.create(null) objects, Map, or Object.freeze(Object.prototype).
