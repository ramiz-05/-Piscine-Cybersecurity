Depending on the module you want to run, ensure you have the following installed on your machine:
* **Git**
* **Linux / Unix-based environment** (or WSL on Windows) for Shell & Linux tasks
* **Python 3.x**
* **Docker** (for containerized tasks)
* A modern **Web Browser** (for HTML/CSS/JS modules)
