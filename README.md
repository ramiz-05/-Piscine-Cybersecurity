 Personal Portfolio Website - Ramez Abu Ramadan

A responsive, interactive personal portfolio website showcasing my journey as a Software Engineering student, my technical skills, and my featured projects. 

 🚀 Features

	Light/Dark Mode Toggle: A custom "Galaxy" dark theme and a clean light theme, allowing users to switch based on their preference.
	Interactive Skill Cards: Clickable skill cards that expand to reveal detailed information using modern CSS and JavaScript.
 	Responsive Design: Fully responsive layout built with CSS Flexbox and media queries, ensuring the site looks great on desktops, tablets, and mobile devices.
	Orbit Animation Profile: A unique, CSS-animated rotating orbit around the profile picture.
	Direct Contact Form:** A fully functional contact form integrated with `mailto:` that directly opens the user's email client to send messages to `ramizaboramadan2@gmail.com`.

 🛠️ Tech Stack

	HTML5: Semantic markup and structuring.
	CSS3 : Modern styling, Flexbox, custom properties (variables), gradients, and keyframe animations.
	JavaScript : DOM manipulation, event listeners, form handling, and theme toggling.

 📂 File Structure

 `index.html`: The main HTML document containing the structure and content of the portfolio.
 `style.css` : The stylesheet containing all visual designs, theme variables, and animations.
 `script.js` : The JavaScript file handling the theme toggle, interactive cards, and contact form logic.
 `assets/myprofile.jpeg` : Profile picture used in the About section.
