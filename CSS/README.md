# Project 02: CSS & Visual Presentation 🎨

This repository contains my solutions for **Project 02: CSS & Visual Presentation**, focusing on designing modern user interfaces using CSS. 

If HTML is the bones of a web page, CSS is the architecture and paint. This project builds on foundational HTML by introducing styling, layouts, and animations to create visually appealing web pages.

## 📁 Repository Structure

| Directory | Exercise Name | Description | Concepts Covered |
| :--- | :--- | :--- | :--- |
| `ex00/` | Flexbox Layout | Designing flexible and responsive container layouts. | `display: flex`, alignment, justification, responsive design principles. |
| `ex01/` | Positioning | Placing elements precisely on the webpage. | `position: absolute`, `relative`, `fixed`, `sticky`, z-index. |
| `ex02/` | CSS Shapes | Creating visual shapes entirely out of CSS without images. | `border-radius`, advanced borders, geometric styling. |
| `ex03/` | Colors & Opacity | Working with different color models and transparency. | Hex, RGB(A), HSL(A), `opacity`, gradients. |
| `ex04/` | The Box Model | Mastering the core CSS Box Model to control spacing and sizing. | `margin`, `padding`, `border`, `box-sizing: border-box`, `width`/`height`. |
| `ex05-bonus/` & `ex06-bonus/` | Animations & Transitions | Adding interactive movement and dynamic state changes. | `@keyframes`, `transition`, hover effects, transform properties. |
