# Project 01: HTML Fundamentals 🌐

This repository contains my solutions for **Project 01: HTML Fundamentals**, a foundational web development project focused on building the structural skeleton of web pages using HTML5. 

The exercises are designed to progress from basic page structures to complex semantic architectures, adhering strictly to web standards and best practices.

## 📁 Repository Structure

| Directory | Exercise Name | Description | Concepts Covered |
| :--- | :--- | :--- | :--- |
| `ex00/` | Empty Static Page | A minimal, valid HTML5 boilerplate document with a specific title. | Document structure, `<!DOCTYPE html>`, `<head>`, `<body>`, `<title>`. |
| `ex01/` | Text Hierarchy | A semantic page titled "Why I Am Learning to Code". | Heading levels (`<h1>`-`<h6>`), paragraphs (`<p>`), emphasis (`<strong>`, `<em>`), strict hierarchy without skipping levels. |
| `ex02/` | Links & Images | A page featuring internal, external, and email links, along with embedded media. | Anchor tags (`<a>`), relative/absolute paths, `<img>` tags, `mailto:` links. |
| `ex03/` | Lists & Tables | A page displaying ordered/unordered lists and a semantic weekly study timetable. | `<ul>`, `<ol>`, `<li>`, semantic tables (`<table>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>`). |
| `ex04/` | Forms & Inputs | An accessible user registration form with native HTML5 validation. | `<form>`, `<input>` (text, email, password, radio, checkbox), `<label>`, `<button>`, required attributes. |
| `ex05/` | Semantic Architecture | A structured technical blog page utilizing HTML5 landmark elements. | `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<footer>`. |
